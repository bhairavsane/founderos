---
description: Reproduce, root-cause and fix a bug with a regression test
---
1. Load `engineering-core` and `debug-root-cause`.
2. Reproduce deterministically; write a failing regression test; show it red.
3. Identify and state the root cause with evidence. Fix the cause with the smallest change.
4. Run `verify.sh`; run `self-review`. Report cause, fix, and why it cannot recur.
